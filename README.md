This repository showcases the projects and assignments I completed during my internship at Ai-Variant. The focus of my work was on data cleaning, analysis, visualization, and dashboard creation using tools such as Excel, SQL, Power BI, and Tableau.

Projects Included
- Olist Store Data Analysis
    Objective: Analyze e-commerce data from Olist to derive insights on order trends, shipping performance, payment methods, and customer reviews.
    Work Done:
        Cleaned and merged multiple datasets (orders, payments, reviews, products, geolocation).
        Calculated key metrics like shipping days, sales per category, and review distributions.
        Built dashboards in Excel, Power BI, and Tableau for interactive visual exploration.
        Solved SQL queries to compute KPIs like total revenue, top cities, and review-based analysis.

- Crowdfunding Campaign Analysis
    Objective: Explore Kickstarter-like crowdfunding data to uncover campaign success patterns.
    Work Done:
      Cleaned raw data (removed duplicates, formatted dates, handled missing values).
      Transformed epoch timestamps into readable date formats for time-based analysis.
      Analyzed success rates by category, country, and goal amount.
      Built dashboards in Excel, Power BI, and Tableau to visualize campaign performance and trends.
      Used SQL for summarizing campaign statistics, goal achievement rates, and backer data.

- Manufacturing Store Analysis
    Objective: Perform sales and operational analysis of a manufacturing business dataset.
    Work Done:
      Cleaned and prepared data for reporting.
      Solved SQL queries to generate sales summaries, identify top-performing products, and monitor stock levels.
      Developed dashboards using Excel, Power BI, and Tableau that highlighted revenue trends, stock movement, and regional sales patterns.

Tools & Technologies

  Tableau — Building dynamic visualizations and exploring data trends
